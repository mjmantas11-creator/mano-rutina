# Mano rutina

Kasdienės rutinos programėlė (React + Vite). Duomenys saugomi naršyklės `localStorage`.

## Paleidimas

```bash
npm install
npm run dev
```

## Etapai

- **01 etapas** – kasdieniai veiksmai: pridėti, pervadinti, ištrinti, pažymėti „Atlikta“.

## Struktūra

- `src/App.jsx` – sąsaja ir veiksmų logika
- `src/storage.js` – skaitymas / rašymas į localStorage (raktas `mano-rutina:veiksmai`)
- `src/styles.css` – stiliai
